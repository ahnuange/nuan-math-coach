# nuan-math-coach · 数学教练

**它不是答案生成器，是一个会忍住不给答案的数学教练。**

孩子把一道卡住的数学题交给它，它不直接给答案：先看卡在哪一步，一次只问一个问题，按孩子的反应换画图、摆实物、给一小截示范；在支持网页同屏预览的电脑端工具里，碰到复杂应用题（新加坡条形建模）、动点拐点、割补翻折、等式天平或含参函数，会写一页能亲手拖着看的图形页，孩子点一下那个文件，就在聊天框旁铺开，左边问一句、右边孩子自己动手拖；等孩子把结果放回原题验过合理、撤掉页面在草稿纸上画对新场景变式题、并且说得出这招什么时候不管用，才算过。

适用：小学三年级及以上、初中、高中（高中段的做法来自真实高三沟通与作者判断，尚未做独立效果验证）。二年级及以下不启动对孩子的引导——那个年纪的数量关系要用实物、手指、钱币、积木摸出来，对着屏幕问答帮不上忙；但它不把人挡回去，会转成家长实物模式，教你怎么用积木、钱币、分水果陪孩子亲手体验数学关系，东西必须过孩子自己的手。

## 它做什么

- 一次只问一句，第一个问号落笔就停，等孩子回答，不连珠炮发问、不催快慢
- 卡住时画结构图（对齐条、线段图、几何草图、面积格）或让孩子摆实物、给半截示范，而不是直接喂答案
- 遇到孩子喊「脑子里没画面」，或者碰上未学方程的复杂应用题（移多补少、和差倍、年龄、盈亏、还原、假设法、多层分数百分数）、几何动点拐点、割补翻折、等式天平、含参函数，不问孩子要不要，直接在电脑端聊天框旁铺开对应的同屏可拖页面（共五张核心页，新加坡条形建模居首，只给条块零件让孩子亲手拖，不端成品图）；再通过「我画你指 → 我画第一排基准条你纸上补第二排 → 变式题空手画草图」三阶交笔，让孩子真正学会自己动笔画图解题
- 把小初高常用的数学思考方法（立 1 份框盯死不变量、每步带单位认清是谁、大数换小数、定格试下一秒／极端探界、文字图象符号互翻、有序排队防漏、倒着退一步、长句切块与两头搭桥）藏进卡壳处的一句大白话追问里，绝不抛术语背口诀；算完必过「三秒荒唐雷达（末位、数量级与生活标尺）」和「代回原题两头对账常验算」
- 动嘴前先在内部算出标准答案，保证给出去的台阶和可见旁白都不漏答案
- 把孩子自己讲通的那道题和他的原话记进他自己的「思维档案」；这次没走通的点、预习留下的猜想只记在大人的待回访清单里，不进孩子的档案
- 怎么开口不死卡年级，看孩子能不能离开眼前这道题说清道理：做给我看指着说／一句话说出这类题长什么样／举出一个失灵反例再说成立条件（细则见 `SKILL.md` 第七节）

## 它不做什么

- 不直接给答案。对孩子绝不说「我不能告诉你答案」，直接说「咱们先看一件事，……」
- 不做能做题能记分的网页小工具、闯关游戏、题库；那一页能拖的页面只服务眼前这一道题，一题一页，做完就关
- 不承诺提分、不承诺开窍，不评价孩子聪不聪明、专不专注
- 不问「你听懂了吗」，不做掐表限时训练，不押题，不代替学校课堂进度
- 不评判学校和老师，不说「AI 比老师更懂」
- 不做能力或心理诊断报告：卡点判断只是这一轮怎么帮他的假设

## 怎么用

> 第一次给孩子用之前，请先看 [`references/家长须知.md`](references/家长须知.md) 那一页。

1. 推荐在支持网页同屏预览的电脑端工具里给孩子用：左边是聊天框，需要时它写一页图形，孩子点一下那个文件，右边就显示出可拖拽的条形图或动点图。孩子自己就能左聊右拖，不用大人帮忙找文件、切窗口，也比盯着手机小屏幕舒服。
2. 把题发进来（打字、语音、拍照都行）。拍照前先把姓名、班级、学校名遮掉。
3. 使用者是孩子本人：家长可以在旁边安静看着，不进对话、不抢答、不提示、不纠正。
4. 孩子转头问家长要答案时，只回这一句：「你去问它，但别让它直接告诉你。」
5. 在晚辅、托管站，或者家里几个孩子共用一台电脑时，大人可以先在内部目录放一页 `背景约束.md`：孩子最怕听哪种话、绝对不能拿谁作比较、家里正在立什么规矩。它会烂在肚子里守住，绝不对孩子说破。

如果孩子说「明天一早要交，真来不及了」，它不会松口喂答案，但会先接住时间，把任务缩成十分钟能走完的一小步，剩下的留明天。

## 记录放在哪

一个孩子分开两个本机目录（用孩子自己起的代号，不用真名、学校和班级）：

- `./孩子-{昵称}/思维档案.md`：**唯一给孩子自己回看的文件**，只记他啃下来的题和他的原话；
- `./_内部-{昵称}/`：**只给大人复盘的目录**，放 `内部日志.md`（含教练内部算好的本题标准答案与七条自检）、`待回访清单.md` 以及可选的 `背景约束.md`。

正课对话中途绝不写文件，等孩子说停或本轮收尾后一次性存盘，也不会把内部文件名发给孩子。记录只留在你自己这台电脑上，不上传；纯网页聊天写不了文件时，收尾会把摘要贴出来请大人自己留存。

## 怎么装

一句话版本（直接对着你的 AI 说）：

> 安装 github 上的 nuan-math-coach skill：https://github.com/ahnuange/nuan-math-coach

装好以后输入 `/nuan-math-coach` 就开始了。

对面要是不认这句话，退一步让它自己找位置：

> 把这个 skill 装到你读 skill 的那个目录里，装完告诉我怎么触发：https://github.com/ahnuange/nuan-math-coach

手动安装：把整个 `nuan-math-coach/` 目录放进你所用工具的 skills 目录，保持 `SKILL.md` 与 `references/` 的相对位置不变。常见位置举例：

- Claude Code：`~/.claude/skills/nuan-math-coach/`
- Cola：`~/.cola/accounts/<账号>/skills/nuan-math-coach/`（在技能列表里能看到实际目录）

触发方式都是 `/nuan-math-coach`。不支持 skills 机制的工具，直接把 `SKILL.md` 全文粘进系统提示词也能完整运行。

### 有新版本时会提醒你

包里带了一个 `scripts/check-update.sh`，每次一轮对话跑完收尾的时候，它会在后台看一眼公开仓库的 `UPDATE.json`。真出新版了，它会在收口那句话之后加一行，长这样：

> 数学教练出新版了（v1.8.0 → v1.8.1），这次把散在各节的五类禁令收进一处，孩子那边怎么带没有变。回复 1，我现在帮你更新。

括号里是你手上的版本和最新版本，中间一句是这一版改了什么，末尾问你要不要更新。

**回复一个 1，它自己就把新版换好了**，不用你去翻 GitHub。换之前整份旧目录先备份到 `~/.nuan-math-coach/backup-v旧版本-时间/`，换完回读一遍对得上才算成功，中途任何一步出错都会把旧的盖回去。

它不会在开会话头一句就冒出来打扰孩子，也不会不问你一句就自己换。24 小时内最多联网一次，没网、没权限、读不到远端就一声不吽。想自己查一次：

```bash
bash nuan-math-coach/scripts/check-update.sh --ignore-cache
```

### 机器跑不了脚本怎么办

这台机器要是没有 bash，比如 Windows，上面那两个脚本都跑不起来，收口时的版本提醒也不会出现。这不影响孩子做题，只影响更新。那种情况按 `SKILL.md` 第十节那段规程手动更新就行，三步，比为了更新去装一个运行环境省事。

- 覆盖小学三年级至高中是**适用范围说明，不是提分效果承诺**。
- 本工具未做过随机对照学业实验；文献用于解释设计依据，不构成对任何孩子成绩结果的保证。
- 本地记录严格双目录隔离：给孩子看的只有 `思维档案.md`，含标准答案的 `内部日志.md` 与 `待回访清单.md` 独立存放在 `_内部-{昵称}/`。
