# nuan-math-coach · 数学思考教练

**它不是答案生成器，是一个会忍住不给答案的数学思考教练。**

孩子把一道卡住的数学题交给它，它不直接给答案：先判断卡在哪里，一次只问一个问题，按孩子的反应换表征或给一小部分样例；等他能用新表征把同类题独立做对，才算过。

适用：小学三年级及以上、初中、高中（高中段的做法来自真实高三场景，尚未做独立效果验证）。二年级及以下不启动——那个年纪的数量关系要用实物、手指、钱币、积木摸出来，屏幕帮不上忙。

## 它做什么

- 一次一句地问，等孩子回答，不连续发问、不施加时间压力
- 卡住时换表征（说 → 画 → 摆实物），或给一个部分样例，而不是给答案
- 先自己把答案算出来（内部），保证给出去的提示不泄露答案
- 把孩子讲出的卡点记下来，形成他自己能回看的「思维档案」
- 按学段换对话方式：小学靠实物与图，初中靠关系与依据，高中靠方法选择与体系定位

## 它不做什么

- 不直接给答案。对孩子不会说「我不能告诉你答案」，而是说「我先问你一件事……」
- 不承诺提分、不承诺开窍，不评价孩子的能力、智力或注意力
- 不问「你听懂了吗」，不做限时训练，不押题，不代替学校的进度
- 不评判学校和老师，不说「AI 比老师更聪明」
- 不做诊断报告：卡点判断是这一次的假设，不是孩子的档案

## 怎么用

> 第一次给孩子用之前，请先看 [`家长须知.md`](家长须知.md) 那一页。

1. 把题发进来（打字、语音、拍照都可以）。题目拍照前先把姓名、班级、学校名遮掉。
2. 使用者是孩子本人：家长可以在旁边安静看着，不进入对话、不抢答、不提示、不纠正。
3. 孩子问家长要答案时，那句标准回法是：「你去问它，但别让它直接告诉你。」

如果孩子说「明天要交」「来不及了」，它不会松口给答案，但会先把时间接住，再把任务缩到最小——今天只走第一步，剩下的留明天。

## 记录放在哪

一个孩子一个目录：`孩子-{昵称}`，昵称自己起，不用真名、不写学校班级。目录里三份固定文件：`内部日志.md`、`思维档案.md`、`待回访清单.md`。

**下次开场它会先读回来**——孩子说「上次那道题」，它知道是哪一道。记录留在你自己机器上，不上传。换不了文件的环境会按格式贴出来，你自己留着就行。

## 怎么装

把 `nuan-math-coach/` 目录放进你的 skills 目录，保持 `SKILL.md` 与 `references/` 的相对位置：

- Claude Code：`~/.claude/skills/nuan-math-coach/`
- Cola：`~/.cola/skills/nuan-math-coach/`

触发方式：`/nuan-math-coach`。

没有 skills 机制的模型也能用：规则全部写在 `SKILL.md` 一个文件里，把它作为系统提示直接贴进去即可；`references/` 只是完整版附录，不装也能跑。这种环境写不了文件——内部日志与思维档案会按固定格式贴出来，你自己留着就行。

## 边界（先说清楚）

- 本 skill 覆盖小学三年级到高中是**适用范围的宣称，不是效果的宣称**。
- 它没有做过对照实验，也没有独立的学业效果证据。文献能解释它为什么这样设计，不构成对任何孩子学习效果的承诺。
- 卡点判断是教学假设，不是诊断结论；需要专业诊断的情况请找专业人士。
