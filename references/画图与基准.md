# 画图与基准（v1.3.0 新增附录）

> 这份附录解决一件事：**孩子卡在「关系」而不是「计算」时，怎么让结构图出现在对话里，并且不出错。**
> 2026-11-21 现场复盘发现两个硬事实：①纯文字讲不清关系，孩子听不懂追问，最后只能靠人关掉 AI 去白板画；②画出来的图如果基准画反了，比不画更糟——那天讲课的人自己第一遍就画反了（把「多的是巧克力的 1/6」说成「多的是奶糖的 1/6」），是旁边的人纠正后才重画。所以画图必须配一道核基准的动作，缺一半就会带着孩子一起错。

## 一、什么时候必须画（分类触发，不是每题都画）

**必须画**——出现下列任一情况，先画图再往下走，不许只用文字讲：

1. **分数、百分数、比、比例**里出现「比谁多／比谁少／是谁的几分之几／占到多少」
2. **几何**（图形、角、线段、面积、周长、证明）
3. **公式推导**（平方差、完全平方、乘法分配律、面积体积公式）
4. 孩子**连续两次**在同一处绕不出来，或者给出一个**看起来对、其实是套来的**答案（典型：多 1/6 就少 1/6、多 1/6 就多 1/7）
5. 孩子说「我不懂」但**说不出卡在哪个动作**

**可以不画**：纯计算、只差最后一步的运算、孩子已经能一句话说清关系、时间只剩一两分钟（这时不硬塞图，改成约下次）。

**不硬在每一题上**：小学高年级作业量大，题题画图会变成负担，孩子会把画画成形式交差。按上面的清单触发，画也只画结构，不画细节。

## 二、三种能用的画法（纯文本环境也能出图）

### 1 对齐条（方块图）——分数、比、倍数、和差倍最通用

只画两排对齐的格子，多出来的那份用括号标出来。**不写答案，不写等号。**

```
巧克力：■■■■■■            6 份
奶糖：  ■■■■■■■            7 份
              └┬┘
          多出来的这 1 份
```

问句只问指认：「哪一排是被比的那一堆？」「多出来的是谁的几分之几？」

### 2 线段图——行程、工程、部分与整体

```
甲 ├────┬────┬────┬────┤
乙 ├────┬────┬────┤
                └ 差这一截是谁的几分之几？
```

### 3 面积格——乘法公式、分配律、平方差、完全平方

```
         a          b
   ┌──────────┬────────┐
 a │   a×a    │  a×b   │
   ├──────────┼────────┤
 b │   b×a    │  b×b   │
   └──────────┴────────┘
```

先让孩子逐格说「这块面积是多少」，再问「四块加起来一共多少」，公式让他自己拼出来——**不要替他把 a²+2ab+b² 写出来**（铁律 8）。

### 三种都画不出来时

退回「用嘴画图」：让孩子把图讲出来——**谁是那个被比的东西、要分成几份、多出来的那一份怎么放**。语言可以当图的支架，符号不行。

## 三、画完核基准：四句话，一句都不能省

图一出来，立刻按顺序问完这四句，再谈计算。**这一步不是为了验图好不好看，是为了验「被比的那一堆」有没有认错。**

1. **回念原句**：把题目里那句关系原样念一遍（不解释、不简化）。
2. **指认基准**：「这句话里，多出来（或少掉）的那一份，是**谁的**几分之几？指着图告诉我。」
3. **交换方向**：「现在反过来问，分母换成哪一排了？」
4. **落到数字**：「那这一份，占新的这一堆的几分之几？」

四句都答得出，图才算数。第 2 句答错，**不改图、不纠正，让他自己把原句再念一遍**——大多数时候他自己会改口。

## 四、基准陷阱清单（按题型查）

| 题面说法 | 基准（单位 1）是谁 | 该问的那一句 |
|---|---|---|
| 甲比乙多 1/6 | 乙 | 「多的这一份，是拿谁去分的？」 |
| 甲比乙少 1/4 | 乙 | 同上 |
| 甲是乙的 3/5 | 乙 | 「把谁分成 5 份？」 |
| 涨价 20% 后又降价 20% | 两次基准不同（原价 → 涨后价） | 「第二次降，是按哪个价降的？」 |
| 打八折 | 原价 | 「八折是打掉原价的几成？」 |
| 含盐率 20% | 盐水总量（不是水） | 「20% 是盐占谁的？」 |
| 速度提高 1/4 | 原速度 | 「快出来的这一段，是原来速度的几分之几？」 |
| 第一天读全书的 1/5，第二天读剩下的 1/4 | 第一天是全书，第二天是**剩下的那部分** | 「第二天读的是哪一堆的四分之一？」 |
| 平均分给 5 人后又多来 2 人 | 人数变了，总数不变 | 「现在要分成几份？」 |

## 五、几何的隐含条件：让孩子自己调出来

几何题最常见的卡点是：**题目不会提醒你它带着什么性质。** 不替他说，只问一句「这个图形、这条线、这个点，你学过它什么？」——让他自己报，报不出来才算没掌握。

| 题面出现 | 该被孩子自己想起的性质 |
|---|---|
| 等腰三角形 | 两底角相等；顶角平分线、底边中线、底边高**三线合一** |
| 直角三角形 + 斜边中点 | 斜边中线等于斜边一半 |
| 中点 + 中线 | 分出的两个三角形面积相等 |
| 垂直平分线 | 线上任一点到两端距离相等 |
| 角平分线 | 到两边距离相等 |
| 平行线 | 同位角相等、内错角相等、同旁内角互补；夹在两平行线间的同底三角形面积相等 |
| 圆 | 半径处处相等；直径所对的圆周角是直角；同弧所对圆周角相等 |
| 正方形、矩形、菱形 | 对角线互相平分（矩形还相等，菱形还垂直） |
| 相似、全等 | 对应边成比例／对应元素相等；先找相等的角 |

**问法是「你学过它什么」，不是「它有这个性质你知道吗」。** 前者要他自己调，后者只是告知。

## 六、孩子卡住时，让他说出那个动作的名字

孩子说「不懂」，常常是不知道自己在哪一步停住了。开场就给他一句安全感：

> **你卡住的那个动作，直接说出它的名字就行。说得越具体，我越能帮你。**

常用的动作词（他报得出，就直接在那个动作上给最小一步的帮助）：

不会去括号｜不会通分｜不会约分｜不会移项｜不会合并同类项｜不会配方｜不会设未知数｜不会列方程｜不会画线段图｜不会算平方｜不会开方｜不会单位换算｜不知道先算哪一个｜不知道从哪开始

**他说得出动作名，问题就已经解决一半**——那说明他知道自己缺的是哪一块砖，而不是笼统地「数学不好」。

## 七、三条禁则

1. **不许把答案写进图里**（不标结果、不标等号右边的数）——图只放结构。
2. **一图只讲一个关系**。想讲两个关系就画两张，别叠成一张孩子读不懂的图。
3. **不许用图代替孩子说话**。画完必须让他指认、让他复述；他说不出来，图就只是又一张别人给的答案。
