# 画结构图与按图型分轮核对

> 对应 `../SKILL.md` 第五节与第十节。这份附录解决两件事：① 孩子卡在数量关系或图形位置时，纯文字追问只会越问越懵，必须把结构图画出来；② 图画出来如果不让孩子核对，画反了或者看岔了比不画更糟，但**不同题型的图要核的东西不一样**，绝不能拿分数应用题那四句话硬套几何题，而且核对必须**一轮只问一句、问号落笔即停**。

## 一、什么时候必须画图（按题型和卡点触发，不题题硬画）

遇到下面五种情况之一，先画结构图再往下问，不许只靠纯文字空讲：

1. **分数、百分数、比和比例**里出现「谁比谁多／少几分之几」「是谁的几分之几」「占百分之多少」；
2. **几何与动点题**（图形、角度、线段和差、动点走路线、面积周长、几何证明）；
3. **乘法与面积公式推导**（乘法分配律、平方差、完全平方、图形割补面积）；
4. 孩子在同一小步**连卡两轮绕不出来**，或者顺嘴报出一个套路假答案（典型：甲比乙多 1/6，反过来就答乙比甲少 1/6）；
5. 孩子喊「我不懂」，但说不出自己卡在哪个具体动作上。

**什么时候不用画**：纯计算、只差最后一步加减乘除、孩子已经一句话把关系讲明白了，或者离交作业只剩两三分钟（这时候先缩成最小一步，不硬塞画图负担）。

## 二、纯文本环境都能直接画的四种结构图

### 1. 对齐条（方块图：分数、倍数、比和比例最顺手）

画上下对齐的两排方块，多出来或少掉的那一截单独标清，**严禁在图上写最后得数或等号右边的答案**：

```text
巧克力：■■■■■■            6 份
奶糖：  ■■■■■■■            7 份
              └┬┘
          多出来的这 1 份
```

### 2. 线段图（行程相遇、工程分段、部分与整体）

```text
A ──────► P ────────────── B
|← 已走 t →|←  剩下的 BP  →|
|←─────── 全长 16 ────────►|
```

### 3. 几何与动点路线草图（标清顶点、直角与动点方向）

```text
A
|\
| \  20
|  \
|16 \      P 从 A 往 B 走（每秒 1）
|____\     Q 从 B 往 C 再往 A 走（每秒 2）
B 12  C    角 B 是 90 度
```

### 4. 面积格（乘法分配律、平方差、完全平方）

```text
         a          b
   ┌──────────┬────────┐
 a │   a×a    │  a×b   │
   ├──────────┼────────┤
 b │   b×a    │  b×b   │
   └──────────┴────────┘
```

（先让孩子一格一格说出面积，再问四块合起来是多少，绝不替他先把 `a²+2ab+b²` 写出来。）

实在连字符图都不好排时，退回「用嘴摆图」：请孩子口头说清楚把谁分成几份、多出来的那一份摆在哪一排后面。

## 三、画完按图型分轮核对（严禁同轮四连问，严禁拿分数题硬卡几何题）

图发出去之后，必须按对应图型让孩子指认核对，**每一轮只问其中一句，等孩子答完再问下一句**：

### 图型 A：分数、百分数、比与比例（核清「单位 1」基准四步，分四轮问）

1. **第一轮·回念原句**：请他把题目里讲「谁比谁多（或少）」的那句原话一字不漏念一遍；
2. **第二轮·指认老基准**：「看着上面这张图，多出来（或少掉）的那 1 份，是拿哪一排去分的？」（要是这句他答反了，不改图也不批他，请他把题目原句再慢念一遍，十有八九他自己就改过来了）；
3. **第三轮·看清换分母**：「现在题目反过来问少几分之几，拿去当分母的那一堆换成哪一排了？」；
4. **第四轮·落到份数比**：「那刚才多出来的这 1 份，占新分母这一排的几分之几？」。

### 图型 B：几何与动点题（核清位置与固定条件，挑卡点项单问）

几何图里没有「谁比谁多几分之几」，不要硬套上面那四句！按题目需要分轮核清：
- 动点从哪个顶点出发、顺着哪条边往哪儿走；
- 图上哪个角是直角、哪两条边相等是题目已经钉死的；
- 在当前这一小问里，动点走到了哪条边上，走过的路程是哪一截。

### 图型 C：乘法与公式面积格（逐格核长宽）

分轮请孩子指出每一小格的长是谁、宽是谁，再问拼成整块后哪几格加在一起，公式由他自己合并出来。

## 四、常见基准陷阱速查表（分数与百分数专用）

| 题面常见说法 | 真正拿去当分母的基准是谁 | 单句怎么问孩子 |
|---|---|---|
| 甲比乙多 1/6 | 乙 | 「多出来的这一份，是把谁平均分成 6 份得来的？」 |
| 甲是乙的 3/5 | 乙 | 「图上分成 5 份的那一排是甲还是乙？」 |
| 先涨价 20% 再降价 20% | 第一次是原价，第二次是涨完后的新价 | 「第二次降价的 20%，是在哪个价钱身上往下砍的？」 |
| 打八折出售 | 原价 | 「打八折指的是现在的卖价占原来标价的十分之几？」 |
| 含盐率 20% | 盐加水的盐水总重（不是纯水重） | 「这个 20% 算的是盐占纯水的，还是占整杯盐水的？」 |
| 第一天读全书 1/5，第二天读余下的 1/4 | 第一天是全书，第二天是读剩的那一截 | 「第二天分的这 4 份，拿的是整本书还是昨天剩下来的那部分？」 |

## 五、几何隐含条件：调孩子的动手经验，不考背书

几何题常卡在题目不主动提醒图形自带的性质。别替他报定理，也别像考背书一样问名词，指着具体图形单问这一句：

> 看着图上这个直角三角形（或这个中点、这条垂直平分线），你以前做题拿它算过什么，或者证过什么？

| 题面出现的元素 | 孩子自己常能调出来的使用经验 |
|---|---|
| 等腰三角形 | 两腰相等、两底角相等；底边上的中线、高、顶角平分线是同一条线 |
| 直角三角形 | 斜边永远比两条直角边都长；两直角边平方和等于斜边平方；斜边中线等于斜边一半 |
| 三角形中线／中点 | 把底边平分成两段一样长；分出来的两个小三角形等底同高面积相等 |
| 垂直平分线 | 这条线上随便挑一点，连到线段两头的距离一样长 |
| 角平分线 | 线上一点往角两边作垂线，两条垂线段一样长 |
| 平行线 | 内错角相等、同位角相等、同旁内角加起来 180 度 |
| 圆 | 从圆心连到圆上哪儿都一样长（半径相等）；穿过圆心的直径是半径的 2 倍；直径对着的圆周角是直角 |

## 六、卡壳报动作名参考词表

孩子只会喊「不懂」时，提醒他直接挑下面这些具体动作报名字，报出哪个就只帮哪个：

不会去括号｜不会通分｜不会约分｜不会移项变号｜不会合并同类项｜不会配方｜不知道设谁当未知数｜不会画线段图｜不会算平方开方｜记不清单位进率｜不知道第一步先写啥

## 七、画图三条死禁令

1. **严禁把得数或答案算式标在图上**，图只摆已知结构；
2. **一张图只画一层关系**，两问位置不同就分开画，别糊成一团乱麻；
3. **严禁画完图自己接着往下讲**，图发出去必须配一句指认问题停笔等孩子答。
