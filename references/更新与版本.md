# 收口之后：版本提醒、替他更新、脚本跑不了怎么办

> 对应 `../SKILL.md` 第十节末尾那一小块。这三节全部发生在**整轮彻底收口之后**，而且只说给旁边的大人听。正课中途一个字都不许提版本。

## 一、收口之后：版本提醒（只对大人说一行）

整轮彻底收口、孩子那边的话已经说完，才在后台跑一次版本检查，把有没有新版这件事告诉旁边的大人。**先把收口那句话写完，再跑脚本**，别让孩子盯着转圈等。查法：

```bash
bash "<本 SKILL.md 所在目录>/scripts/check-update.sh"
```

- **有输出**，就原样追加在收口那句话的下一行，单独成段，用引用符号 `>` 起头；
- **没输出、跑不动、连不上网**，直接跳过，一个字都不提，绝不编一句「已经是最新版」；
- 一轮只许出现一次，同一条回复里不许重复出现；
- **正课中途一个字都不许提版本**。孩子思路正在走的时候插一句升级，比不提醒更糟，这一条是硬锁；
- 不许说「你的版本落后了」「旧版本有毛病」这种让人难受的话，也不许拿新版当卖点劝人换；
- 检查结果只给大人看，不解读给孩子听，也不把脚本路径或本地文件夹念出来。

查的是公开仓库里的 `UPDATE.json`，24 小时内最多联网一次，缓存写在 `~/.nuan-math-coach/update_check_at`。这个脚本全程静默失败，没网、没权限、远端格式不对都直接退出不输出，不会打断孩子的对话。

## 二、大人回复了 1：替他更新

提醒末尾那句「回复 1，我现在帮你更新」就是征求同意。成人回了一个 1，才动手。

提醒里那句「{一句话说清这版改了什么}」是发布方写进 `UPDATE.json` 的，必须说清改了哪件事，不写「优化了体验」这种等于没说的空话。

**只有上一条回复末尾带着版本提醒时，一个孤零零的 1 才算同意。** 没有那段提醒，别人说 1、说第 1 问、说 11，都不是这个意思，不许自己猜。孩子乱敲了一个 1、看不出是谁回的，先问一句「这个 1 是想让我换新版吧？」再动。

同意的，先回一句「好，我现在更新，大概几秒」，再跑：

```bash
bash "<本 SKILL.md 所在目录>/scripts/update-skill.sh"
```

更新完只报三句，多了不说：

1. 更新到了哪个版本，一共几个文件
2. 旧版整份备份在哪个文件夹，不放心可以自己盖回去
3. **这个会话加载的还是旧规则，新开一次对话才算用上新的**

更新不成（写不进去、下载不到、校验没过、版本对不上）别当场甩给大人，先按下面第三节那段规程自己换一遍：去拿、逐个核、备份完再盖、盖完回读。三步都试过还是不成，才一句话说清卡在哪，请他改天再试或自己去发布页下载最新包覆盖旧文件夹，不贴整段日志、不贴报错原文。

更新的过程中不许念文件路径，不许一条条报下载进度，不许说「已经生效了」。备份目录没征得同意不许删。

## 三、脚本跑不了怎么办：按规程手动更新

有些机器跑不了上面那个脚本，比如没有 bash，或者宿主根本不给跑命令。碰上这种情况，别把孩子的题卡在这儿，也别编一句「已经是最新版」。按下面三步自己干，一步都不许省：

1. **先比版本。** 读一次远端那份版本清单（`UPDATE.json`，里面写着版本号、一句话说明、每个文件的校验码），跟本机 `SKILL.md` 顶层写着的版本号比一比。远端不高于本地，到这一步就完了，一个字都不用说。
2. **逐个下载，逐个核。** 按清单里的文件清单一个一个下载到临时文件夹。除了主文件，每个文件核一遍校验码；主文件核 `name` 和 `version` 两个字段。对不上就整批作废，一个文件都不换。
3. **先备份再盖，盖完回读。** 把现在的整份 `SKILL.md` 和 `references/` 复制到 `~/.nuan-math-coach/backup-v{旧版本}-{时间}/`，再按清单覆盖。写完打开 `SKILL.md` 读一遍版本号，对不上就把备份整份盖回去，然后一句话说清卡在哪。

三条底线跟脚本里守的是同一套：只覆盖清单里的文件，不删本机多出来的任何一个，不碰工作目录里孩子的档案和日志。下载不到、核不过、写不进去，一句「这次没换成，改天再试」就够了，不贴报错原文、不念路径。

没征得同意，一个字都不许自己动手更新。这是硬锁。
