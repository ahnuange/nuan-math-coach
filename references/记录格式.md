# nuan-math-coach / 内部日志与待回访清单格式

> 对应 `SKILL.md` 第十节。正课对话进行中途严禁创建目录或修改任何文件，一律等孩子说停或本轮彻底收尾后再一次性落盘；给孩子的回复里严禁出现 `_内部-`、`内部日志`、`待回访清单` 等任何文件名或路径链接。

### 内部日志格式（放 `./_内部-{昵称}/内部日志.md`，严禁放进孩子目录）

**提示次数怎么数**：给出字面提示、示范半步、替他画好结构图，或者问句里不小心带出了结构名称（如「把全程当成一整份」），都记 1 次；单纯提问（没给数字、没给拆法、没带结构名，如「48 里面你想先拆哪一块？」）记 0 次；只提醒动作方向、不给内容的（如「算完放回原题验一下」）记 0 次。同一个提示不重复计次。

每轮收尾按日期和轮次追加一节：

```markdown
## {YYYY-MM-DD} 第 {n} 轮

入口判定：{上过了（正课）／没上过（预习）／做过且订正过}｜凭据：{卷面物证或孩子原话}
卡点判断：{第一类}（主）／{第二类}（待定；拿不准就写未定）
使用档位：{一档／二档／三档}；{是否升档}
提示数：开头 {n} → 结尾 {n}（{是否在撤除}）
用的方式：{口述／草稿笔迹／画图／摆实物} → {…}
原题回代与变式：{回代验范围结果}；{变式题目与独立做对／扶过／未完成／预习不出}
孩子意愿：{愿意再来／说停收口／未问}｜内部自验：{整题各问标准答案}（已提前算出，未向孩子泄露）
观察轴／他的叫法：{孩子原话或起的名字}（未验证）

本轮七条自检：
1. 变式与失效边界：{做对情况＋孩子说的边界原话；预习写「预习入口不测」}
2. 提示撤除：{是／否}
3. 自己说出或指出关系：{是／否，具体哪一句}
4. 下次意愿：{愿意／主动叫停}
5. 逐字回看（给下一轮的改进指令）：{哪句话本该留给孩子说，下次怎么改}
6. 画图与按图型核对：{未画／分数倍比已分轮核四句／几何动点已核起点方向与所在边／面积格已逐格核长宽}
7. 裸答案拦截：{严守／违规几次}
```

**写不了本地文件的纯网页环境**：绝不假装已经存好了。收尾后给家长只贴下面两行摘要（不要把含答案的内部自验贴给孩子看），有待回访条目时再把待回访三行贴给大人留存：

```markdown
旁听规则：不抢答、不提示、不纠正。他问你要答案，就说「你去问它，但别让它直接告诉你」。
本轮一行：今天卡在{卡点}，靠{画图／摆实物／拆条件}自己走通的。
```

### 待回访清单格式（放 `./_内部-{昵称}/待回访清单.md`，真有欠账才建）

这次没走通的点、做对变式但没说出失效边界的题、或者课前预习留下的猜想，绝不写进孩子的 `思维档案.md`，统一记在大人的 `待回访清单.md` 里。

**1. 正课未走通或差失效边界（三行一条）：**

```markdown
待回访：{具体题目与卡住的那一步}（{卡点类别}）｜上次：{YYYY-MM-DD}｜没过在哪：{一句话实情}
下次换什么：{下次准备换哪种图、实物或生活场景，不重复这次用过的}
孩子的反应：{愿意再来／累了叫停}｜收口时他的原话：{原话，没有就留空}
```

**2. 预习入口留下的猜想（带三项核查记录）：**

```markdown
待回访：{新课节名或题号}（预习猜想）｜上次：{YYYY-MM-DD}｜凭据：{整页新书无批注／孩子原话「明天才学」}｜有无他自己动笔的那一笔：{有：写了…／无}
他猜的原话：「{一字不改照录}」
下次换什么：等学校上完这节课回来，开场第一句先问「上次让你上课留意的那一处，老师是怎么讲的？」
```

**五条规矩：**
1. **只记具体动作，不记能力评价**（写「拆成 20 和 5 后能算，换买笔场景没自己列出来」，绝不写「乘法基础差」）。
2. **走通就销账**：下次回来啃下来了、说出边界了，按第十二节五行搬进 `思维档案.md`，从待回访清单里删掉；连着两回都没啃动，下次把步子再缩一半或退回摸实物。
3. **不追问「他怎么还不懂」，只定「下次换什么画法再来」**。
4. **不催促、不打卡**：孩子不想做随时停，绝不拿清单逼他清账。
5. **归类权归大人**：AI 只如实记下「没读懂题意／没看出关系／看懂了算错」的现场表现，最终怎么安排复习由带他的大人定。
