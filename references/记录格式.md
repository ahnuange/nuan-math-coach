> 自 SKILL.md 第十节移出（2026-11-22，v1.3.1）。原因：主文件撞上华为云单文件 100 KB 上限。
> 规则不变，这里是模板与填好的样子。两个目录的分工与「什么时候写」在 SKILL.md 第十节。

### 内部日志格式（谁也不给看；放 `./_内部-{昵称}/`，不进孩子目录）

**什么算一次提示**：给出一个字面提示、示范一步、或替他把表征换掉，都算一次；**问句里带了结构名也算一次**（「把全程当成一整份来分」这种，比给数字更贵——它把最难的那一步换成了算）。**只问问题不算**——问句里只要没给出具体数字、没给出具体拆法、也没给出结构名，就不计（「48 里面你想先拿哪一块」是 0 次）。数的是给出去的东西，不是对话轮数。同一次提示不重复计数。**只给方向不给内容的不计**：「算完自己验一遍」不算，「为什么用 1 去除」不算（这两句都没给数字、没给拆法、没给结构名）。

```
卡点判断：{第一类}（主）／{第二类}（待定）
使用档位：{档位}；{是否升档}
提示数：开头 {n} → 结尾 {n}（{撤除情况}）
表征：{语言／图／实物／算式} → {…}
变式迁移：{题目} {独立做对／未完成／未测}
孩子意愿：{愿意再来／不愿意／未问}｜内部自验：{题目与答案}（已算出，未输出；本文件不进孩子目录）
知识轴／他的叫法：{这一类的原话}（未验证）
```

**「存在本地」的前提是能写文件（2026-10-19 补）。** 在能写文件的环境里（Cola、Claude Code 这类），日志、思维档案、待回访清单写进本地文件，不上传。**在只能聊天、写不了文件的环境里（把 SKILL.md 当系统提示贴进去用的那种），不许假装已经存了**——把该记的内容按上面的格式原样贴出来，请大人自己抄存，并说一句「这几行你留着，下次开场发我」。两边的规则一个字都不改，差的只是存哪儿。

家长端只给两行，不给日志：

```
旁听规则：不抢答、不提示、不纠正。他问你要答案，就说「你去问它，但别让它直接告诉你」。
本轮一行：今天卡在{卡点}，用{表征}说通的。
```

### 待回访清单（只在大人这一侧，2026-10-16 补；文件名 2026-10-21 定）

写在 `./_内部-{昵称}/待回访清单.md`，三行一条、跨轮累积（大人这一侧，不进孩子目录）。第一次真有没走通的点时才建这份文件，不预建空壳。

一个点这次没走通：**不进孩子的思维档案，但要在大人这侧留一笔**——不然下一次打开时，前面那一轮就白走了。这是第十二节「不记未攻克的题」的唯一例外，例外只开在大人的账上。

每条三行：

```
待回访：{卡点}（{第一类}）｜上次：{日期}｜这次没过在哪里：{一句话}
下次换什么：{表征或情境}（换掉上次那个）
孩子的反应：{愿意再来／不愿意／未问}｜约下次时他自己说了什么：{原话，没有就留空}
```

五条纪律（第五条 2026-11-06 补）：

- **记动作，不记评价。** 写「25×18 拆数后能说出先算哪一块，变式题没独立做对」，不写「乘法基础差」。
- **只留到回访完为止。** 回访通了，把这笔按第十二节五行挪进孩子的思维档案，清单里删掉；连着两次回访都没走通，不要堆着——把任务缩到更小的一步，或者换一个更靠前的地基点（种子概念先摸实物）。
- **不问「他为什么还没好」，只问「换什么再来」。** 卡点判断是这一次的假设，不是给孩子贴的标签；这里不写能力、不写智力、不写注意力。
- **回访不推送、不打卡、不施压。** 什么时候回访由带他的人定；孩子明确不想继续（第八节）优先于回访——不愿意就不回访，把这一笔留着，不催。
- **归到哪一类，由人定，AI 只摆三档（2026-11-06 补）**。AI 能做的是把这次的记录摆成三档（没读懂／没认出结构／会而算错），供回访时挑；**挑哪一档是带他的人的判断**，AI 不自己落标签。分错了以孩子复述的为准——他把这一步重新讲一遍，讲成什么样就是什么样，不拿 AI 的分类去纠他。

默认节奏：**隔一两天、换一个情境或表征再来一道**，不连出同类题。初高中按模块归、考前回看（第十二节）。
